작게 시작한 첫 번째 앱입니다. 아이디어를 빠르게 만들어 보고, 써 본 사람의 의견을 듣고, 다시 다듬기 위해 만들었습니다.

소개

무엇을 하는 앱인가요

my-app-1은 매일 하는 작은 일을 한곳에 모아 두는 가벼운 웹 앱입니다. 설치 없이 브라우저에서 바로 열 수 있고, 화면은 휴대폰과 데스크톱 모두에 맞춰집니다. 지금은 초기 버전이라 기능이 많지 않지만, 방명록에 남겨 주시는 의견을 보고 다음 버전을 정합니다.

주요 기능

빠른 시작

회원가입 없이 첫 화면에서 바로 사용합니다.

어디서나

휴대폰, 태블릿, 데스크톱에서 같은 화면을 봅니다.

밝게, 어둡게

기기 설정에 맞춰 라이트·다크 테마가 바뀝니다.

시작하기

직접 실행해 보기

# Node.js 22.13 이상이 필요합니다
cd my-app-1
cp .env.example .env   # Supabase URL과 공개 키 입력
npm install
npm start
# 브라우저에서 http://localhost:3000 을 엽니다
